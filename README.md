# Coffee_Sales_Analysis

## Project Overview
This project explores coffee shop sales data using Python to identify sales trends, customer purchasing patterns, popular coffee products, and payment preferences. It also applies time-series analysis to examine sales seasonality and forecast future sales.

## Objectives
- Analyse overall sales performance and transaction amounts.
- Identify popular coffee types and customer purchasing patterns.
- Compare cash and card payment sales.
- Explore sales trends by hour, day, week, and month.
- Detect missing values, duplicate records, and potential outliers.
- Apply time-series decomposition and ARIMA forecasting to estimate future sales.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Statsmodels
- Google Colab
- GitHub

## Project Files
- **Python Notebook:** `Final_coffee_sale.ipynb` — data cleaning, exploratory data analysis, visualisations, and sales forecasting.
- **Presentation:** Final Coffee Sales Analysis PPTX — project findings and visualisations.

## Key Analysis Areas
1. Data cleaning and outlier detection
2. Sales distribution by coffee type
3. Cash versus card sales
4. Purchasing patterns by time and day
5. Daily, weekly, and monthly sales trends
6. Seasonal decomposition and ARIMA forecasting
7. Popular coffee types and card customer purchasing patterns

## Project Goal
To turn raw coffee sales data into meaningful insights that can support better business decisions, sales planning, and an improved understanding of customer purchasing behaviour.
